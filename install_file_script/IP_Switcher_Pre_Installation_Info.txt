IP Switcher Pre-Installation Information
============================================

This tool allows you to manage and configure IP addresses on your selected network interface. Below are the key features:

- Configure Network Interfaces: Set static IPv4 addresses or switch interfaces back to DHCP.
- Save Presets: Store reusable IP, subnet mask, and gateway combinations.
- Import and Export Presets: Easily move preset configurations between machines.
- User-Friendly Interface: Enjoy a GUI-based tool that simplifies network management tasks.

Important Notes:
- Ensure that you have administrator privileges to change network settings.
- This application is compatible with Windows operating systems only.
